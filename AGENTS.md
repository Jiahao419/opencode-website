# Project constraints

- This repository is a static one-page website built with only three assets: `index.html`, `style.css`, and `script.js`.
- Do not introduce build steps, package managers, frameworks, or dependencies. Do not install anything.
- Do not add, rename, or remove files other than `index.html`, `style.css`, `script.js`, `README.md`, `AGENTS.md`, and `.gitignore` unless explicitly requested.
- Keep the light/dark theme toggle working on every change.
- The site must remain responsive for narrow and wide screens.
- Interactive elements (including the theme toggle) must stay keyboard accessible.
- Do not deploy the site or commit/push changes unless explicitly requested by the user.
- Prefer plain HTML, CSS, and JavaScript. Keep changes consistent with the existing structure, naming, and style.
